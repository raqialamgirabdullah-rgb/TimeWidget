# টাইম উইজেট (TimeWidget)

একটি Android হোম-স্ক্রিন উইজেট, তিনটির কাজ একসাথে:

1. **ওপরে:** বড় সময় (বামে) — ইংরেজি তারিখ (ডানে)
2. **মাঝে:** আরবি (হিজরি) তারিখ (বামে) — বাংলা তারিখ (ডানে)
3. **নিচে:** এক লাইনে পাঁচ ওয়াক্ত নামাজের সময় (চলতি ওয়াক্ত হালকা সবুজে চিহ্নিত)

- ইন্টারনেট ছাড়াই চলে (সব হিসাব ফোনেই হয়)।
- বাংলা তারিখ: বাংলাদেশের সংশোধিত পঞ্জিকা (পহেলা বৈশাখ ১৪ এপ্রিল, আশ্বিন ৩১ দিন, ফাল্গুন ২৯/৩০)।
- হিজরি তারিখ: উম্মুল কুরা, ডিফল্টে −১ দিন (বাংলাদেশে চাঁদ দেখা সাধারণত সৌদির একদিন পরে); অ্যাপে ±৩ দিন বদলানো যায়।
- নামাজের সময়: সূর্যের অবস্থান থেকে হিসাব (ফজর/ইশা ১৮°), আসর হানাফি বা শাফেয়ি; স্থান বেছে নেওয়া যায়; প্রতি ওয়াক্ত মিনিটে সমন্বয় করা যায়।
- নেট থাকলে অ্যাপ নিজে নতুন সংস্করণ খুঁজে "আপডেট করুন" বোতাম দেখায়।

**ইনস্টল:** Releases থেকে `TimeWidget.apk` নামিয়ে ইনস্টল করুন → অ্যাপ খুলে "হোম স্ক্রিনে উইজেট বসান" চাপুন।
